# 発展課題

`完成` まで終わった人向けの追加課題です。6 ステップあります。

進め方は本編と同じで、`stepN/index.html` にコードを足していくと `stepN/解答/index.html` と同じものができあがります。
step1 の出発点は `完成/解答/index.html` そのものです。

| ステップ | テーマ | 学ぶこと |
| --- | --- | --- |
| step1 | 完了した TODO をまとめて削除する | `computed` の追加 / `v-if` でのボタンの出し分け |
| step2 | 「すべて / 未完了 / 完了」で絞り込む | `v-else-if` / `class` の動的バインディング |
| step3 | localStorage に保存する | `watch` と `deep` / 起動時の読み込み |
| step4 | ダブルクリックで編集する | 行ごとの一時状態 / `nextTick` / `@blur` / `@keyup.esc` |
| step5 | 未完了を上、完了を下に並べる | 算出プロパティの連結 / `sort()` が配列を壊すこと |
| step6 | 1 行分をコンポーネントに切り出す | `props` / `emit` / コンポーネントの登録 |

各ステップで使う機能の公式ドキュメントは、リポジトリのルートの `GUIDE.md` の「発展版」にまとめてあります。

## 本編との違い

本編は「なぜそう書くのか」を丁寧に説明していましたが、ここからは**やることの指示が中心**です。
手が止まったら解答を見て構いません。写して動かしてから読み解くのも立派な勉強です。

各ステップは前のステップの上に積み上がります。飛ばしたいステップがあるときは、
次のステップの `index.html`(＝前のステップの解答)から始めてください。

## 動かし方

本編と同じく、`index.html` をダブルクリックで開けば動きます。

ただし **step3 以降は localStorage を使う**ので、`file://` で開いた場合は注意してください。
`file://` のページはブラウザから見るとすべて同じ置き場所を共有するため、
`step3/index.html` と `step3/解答/index.html` が同じデータを見ることになります。
混乱したら、開発者ツールの Console で次を実行すると消せます。

```js
localStorage.removeItem('vue-todo-app')
```

## step6 まで終わったら

テンプレートを文字列で書くのがつらくなってきたはずです。補完も色分けも効かず、
コンポーネントが増えるほど 1 ファイルに収めるのが無理になります。

そこが **Vite + 単一ファイルコンポーネント(`.vue`)** に移る頃合いです。
ここまでで学んだ `ref` / `computed` / `watch` / `props` / `emit` は、そのまま `.vue` でも使えます。
