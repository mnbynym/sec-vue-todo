# 完成: 残りの件数を表示する

## ねらい

既にあるデータから計算して求まる値は、`computed`(算出プロパティ)にします。
最後のステップです。

## 出発点

`index.html` は step 6 の完成版(追加・表示・削除ができる状態)です。
件数のところが `0` のまま固定になっているので、ここを本物にします。

## やること

### 1. 算出プロパティを定義する

`removeTodo()` の下に追加します。

```js
        // 算出プロパティ: 未完了の TODO の件数
        // todos が変わったときだけ再計算され、結果はキャッシュされる
        const remainingCount = computed(() => {
          return todos.value.filter((t) => !t.completed).length
        })
```

`computed` は step 2 で import 済みです。

### 2. `return` に足す

```js
        return {
          newTodo,
          todos,
          addTodo,
          removeTodo,
          remainingCount
        }
```

### 3. 件数の表示を書き換える

```html
        <!-- 算出プロパティで残りの件数を表示(1 件以上あるときだけ) -->
        <p v-else>
          残り <span class="badge text-bg-secondary">{{ remainingCount }}</span> 件 /
          全 <span class="badge text-bg-secondary">{{ todos.length }}</span> 件
        </p>
```

固定の `0` を `{{ remainingCount }}` と `{{ todos.length }}` に置き換え、`<p>` に `v-else` を付けます。

`v-else` は、直前の `v-if`(「TODO はまだありません」の `<p>`)と対になります。
これで「0 件のときはメッセージ、1 件以上のときは件数」と、どちらか一方だけが表示されます。

## 知っておくとよいこと

- **`computed` は依存しているデータが変わったときだけ再計算され、それ以外のときはキャッシュされた結果を返します。**
  同じ処理を関数(メソッド)として書くこともできますが、その場合は画面が描き直されるたびに毎回実行されます
- `remainingCount` も `ref` と同じく、JavaScript の中では `.value` を付けて読みます。テンプレートでは不要です
- `computed` の中では値を書き換えないでください。「今あるデータから計算するだけ」の場所です
- `v-else` は `v-if` が付いた要素の**すぐ隣**に置く必要があります。間に別の要素を挟むとエラーになります

## 動作確認

- [ ] TODO を 2 件追加すると「残り 2 件 / 全 2 件」と表示される
- [ ] 1 件にチェックを入れると「残り 1 件 / 全 2 件」に変わる
- [ ] チェックを外すと「残り 2 件」に戻る
- [ ] 1 件削除すると「残り 1 件 / 全 1 件」になる
- [ ] 全部削除すると件数の表示が消え、「TODO はまだありません。」に戻る

これで TODO アプリの完成です。おつかれさまでした。

## もっとやりたい人へ(発展課題)

解答はありません。ここまでで学んだ書き方の組み合わせで作れます。

1. **完了した TODO をまとめて消す** … 「完了をすべて削除」ボタンを足す
2. **絞り込み** … 「すべて / 未完了 / 完了」を切り替えるボタンと、`computed` で絞り込んだ配列を作って `v-for` に渡す
3. **保存する** … `localStorage` に `todos` を保存し、次に開いたときに読み込む(`watch` を使うと変更を監視できます)
4. **編集する** … TODO の文字をダブルクリックすると入力欄になり、書き換えられるようにする
5. **並べ替え** … 未完了を上、完了を下に表示する
6. **部品に分ける** … 1 行分を `TodoItem` コンポーネントに切り出し、`props` と `emit` でやりとりする

4 以降は、1 ファイルではつらくなってきます。そうなったら Vite + 単一ファイルコンポーネント(`.vue`)への移行を検討する頃合いです。
